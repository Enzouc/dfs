================================================================================
DOCUMENTACIÓN DE APIS PARA POSTMAN - PROYECTO BOOKPOINT CHILE (CON GATEWAY)
================================================================================

   - 200 OK: Éxito
   - 201 Created: Recurso creado exitosamente
   - 204 No Content: Éxito sin contenido de retorno
   - 400 Bad Request: Datos inválidos
   - 404 Not Found: Recurso no existe
   - 500 Internal Server Error: Error interno del servicio

--------------------------------------------------------------------------------
1. CATEGORÍA: AUTENTICACIÓN Y USUARIOS (Auth-Service - vía Gateway)
--------------------------------------------------------------------------------

MÉTODO: POST
RUTA: http://localhost:8080/api/auth/usuarios
DESCRIPCIÓN: Crea un nuevo usuario en el sistema (Admin).
CUERPO (JSON):
{
    "username": "nuevo_usuario",
    "password": "password123",
    "rol": "ADMIN",
    "permisos": ["LEER", "ESCRIBIR"]
}
RESPUESTA EXITOSA (200 OK): Objeto usuario creado con ID.
ESTADOS HTTP: 200 OK, 400 Bad Request.

MÉTODO: GET
RUTA: http://localhost:8080/api/auth/usuarios
DESCRIPCIÓN: Lista todos los usuarios registrados.
RESPUESTA EXITOSA (200 OK): Arreglo de usuarios.

MÉTODO: PATCH
RUTA: http://localhost:8080/api/auth/usuarios/{id}/permisos
DESCRIPCIÓN: Modifica los permisos de un usuario específico.
CUERPO (JSON): ["LEER", "ESCRIBIR", "BORRAR"]
PARÁMETROS RUTA: id (Long)

MÉTODO: DELETE
RUTA: http://localhost:8080/api/auth/usuarios/{id}
DESCRIPCIÓN: Elimina un usuario del sistema.
PARÁMETROS RUTA: id (Long)
ESTADOS HTTP: 204 No Content (Éxito), 404 Not Found (Si no existe).

2. CATEGORÍA: INVENTARIO (Inventario-Service - vía Gateway)
--------------------------------------------------------------------------------

MÉTODO: GET
RUTA: http://localhost:8080/api/productos
DESCRIPCIÓN: Lista todos los productos disponibles.

MÉTODO: POST
RUTA: http://localhost:8080/api/productos
DESCRIPCIÓN: Crea un nuevo producto.
CUERPO (JSON):
{
    "nombre": "Libro de Ejemplo",
    "descripcion": "Descripción detallada",

MÉTODO: GET
RUTA: http://localhost:8080/api/productos/{id}/stock?cantidad={n}
DESCRIPCIÓN: Valida si hay stock suficiente para una cantidad 'n'.
PARÁMETROS QUERY: cantidad (Integer)

MÉTODO: PATCH
RUTA: http://localhost:8080/api/productos/{id}/ajuste?nuevoStock={n}
DESCRIPCIÓN: Ajuste manual de stock por parte de jefe/bodega.
PARÁMETROS QUERY: nuevoStock (Integer)

MÉTODO: DELETE
RUTA: http://localhost:8080/api/productos/{id}
DESCRIPCIÓN: Elimina un producto del inventario.
PARÁMETROS RUTA: id (Long)
ESTADOS HTTP: 204 No Content (Éxito), 404 Not Found (Si no existe).

11. CATEGORÍA: CARRITO DE COMPRAS (Carrito-Service - vía Gateway)
--------------------------------------------------------------------------------

MÉTODO: GET
RUTA: http://localhost:8080/api/carrito/usuario/{usuarioId}
DESCRIPCIÓN: Obtiene el carrito de compras de un usuario registrado
PARÁMETROS RUTA: usuarioId (Long)
RESPUESTA EXITOSA (200 OK): CarritoResponseDTO con items, subtotal, impuestos y total

MÉTODO: GET
RUTA: http://localhost:8080/api/carrito/session/{sessionId}
DESCRIPCIÓN: Obtiene el carrito de compras temporal para un usuario no registrado
PARÁMETROS RUTA: sessionId (String)
RESPUESTA EXITOSA (200 OK): CarritoResponseDTO con items, subtotal, impuestos y total

MÉTODO: POST
RUTA: http://localhost:8080/api/carrito/items?usuarioId={usuarioId}&sessionId={sessionId}
DESCRIPCIÓN: Agrega un producto al carrito
PARÁMETROS QUERY: usuarioId (Long, opcional), sessionId (String, opcional)
CUERPO (JSON): {"productoId": 1, "cantidad": 2}
RESPUESTA EXITOSA (200 OK): CarritoResponseDTO con el item agregado
ESTADOS HTTP: 200 OK, 400 Bad Request

MÉTODO: PUT
RUTA: http://localhost:8080/api/carrito/items/{itemId}/cantidad?cantidad={nuevaCantidad}
DESCRIPCIÓN: Actualiza la cantidad de un item en el carrito
PARÁMETROS RUTA: itemId (Long)
PARÁMETROS QUERY: cantidad (Integer)
RESPUESTA EXITOSA (200 OK): CarritoResponseDTO con la cantidad actualizada

MÉTODO: DELETE
RUTA: http://localhost:8080/api/carrito/items/{itemId}
DESCRIPCIÓN: Elimina un item del carrito
PARÁMETROS RUTA: itemId (Long)
ESTADOS HTTP: 204 No Content (Éxito), 404 Not Found (Si no existe)

MÉTODO: DELETE
RUTA: http://localhost:8080/api/carrito/vaciar?usuarioId={usuarioId}&sessionId={sessionId}
DESCRIPCIÓN: Vacía todo el carrito de compras
PARÁMETROS QUERY: usuarioId (Long, opcional), sessionId (String, opcional)
ESTADOS HTTP: 204 No Content (Éxito)
